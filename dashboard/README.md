# Python dashboard

**[Download Python dashboard ZIP](https://github.com/GeorgePhilippou/portable-potentiostat-handover-personal/raw/refs/heads/main/downloads/Python_Dashboard.zip)**

Runs on the computer. One launcher detects the flashed technique and opens its controls. Extract the ZIP, install `requirements.txt`, then run `potentiostat_dashboard.py`. Keep the files and `dashboard_assets` folder together. No separate dashboard download is needed for each technique.

[Choose/download firmware for the MSP430](../downloads/README.md) · [Setup guide](../docs/START_HERE.md)

Editable sources: [launcher](../CCS_Import_Projects/potentiostat_dashboard.py), [dashboard engine](../CCS_Import_Projects/ec_dashboard.py), [dependencies](../requirements.txt). [Customisation guide](../docs/CUSTOMISATION.md).
