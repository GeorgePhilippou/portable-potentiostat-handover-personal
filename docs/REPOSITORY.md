# About this personal handover copy

This public repository is George Philippou's temporary distribution copy of the portable potentiostat handover. It provides immediate access while access to the lab repository is arranged.

The [Non-Invasive Bioelectronics Lab repository](https://github.com/Non-Invasive-Bioelectronics-Lab/portable-potentiostat-handover) remains the main version. It is currently private and needs an invitation. This personal copy is a separate snapshot and does not synchronise automatically.

## Download and start

Open [Downloads](../downloads/README.md), choose the firmware ZIP for your technique and download the shared Python dashboard ZIP from the same page. No account or invitation is required for this public copy. Extract both and follow [Start here](START_HERE.md).

Both downloads contain editable source. Keep the ZIPs as your baseline and make changes in a separate extracted local copy. You do not need Git or permission to push changes. The [customisation guide](CUSTOMISATION.md) identifies the settings and functions to edit. Local changes do not alter either GitHub repository.

This copy uses lab source commit `3eaae751ed7d65a48dd6f0718712464d4a3d1911`, copied on 20 October 2026. Only distribution links and personal-copy documentation were changed; acquisition firmware is identical. The dashboard excludes the demo-only RC fitting tool. EIS remains in development; read the [tested settings and limits](VALIDATION.md).

Public visibility allows access to the files; it does not replace the vendor licence terms in [third-party notices](../THIRD_PARTY_NOTICES.md).
